# Research

## Uncertainty-Aware, Regime-Adaptive Workload Forecasting for Cost-Efficient Cloud Autoscaling

### Research Question

Can a workload forecasting system that understands **when it is uncertain** and **when workload behavior has changed** make better cloud-autoscaling decisions than systems optimized only for forecasting accuracy?

### Approach

```text
Workload Data
     ↓
Data Preparation
     ↓
Probabilistic Forecasting
     ↓
Uncertainty Estimation
     ↓
Regime / Change-Point Detection
     ↓
Horizon-Aware Evaluation
     ↓
Autoscaling Simulation
     ↓
Cost + SLA Analysis
```

### Key Components

* Probabilistic workload forecasting
* Quantile / uncertainty-based forecasting
* Regime-shift detection
* Change-point / drift detection
* Multiple forecasting horizons
* Autoscaling simulation
* Cost-efficiency analysis
* SLA-violation analysis

### Research Objective

Rather than treating **forecast accuracy as the final objective**, the project connects ML forecasting performance to the downstream engineering question:

> **Does better uncertainty-aware forecasting produce better autoscaling decisions?**
